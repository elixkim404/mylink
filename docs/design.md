## 1. 개요 (Overview)

본 문서는 **MyLink**의 핵심 화면인 **방문자 전용 퍼블릭 프로필 메인 화면(`/@handle`)**과 **QR 코드 공유 모달**의 UI 레이아웃, 와이어프레임, 인터랙션 및 토스 디자인 시스템(TDS) 기반 디자인 토큰 규칙을 정의합니다.

- **기본 해상도**: 모바일 뷰포트 기준 (`375px ~ 430px`, max-width 430px 중앙 정렬)
- **디자인 원칙**: TDS(Toss Design System)의 간결함, 높은 가독성, 매끄러운 햅틱 인터랙션 및 신뢰감 제공

## 4. 주요 영역별 UI 및 인터랙션 상세 명세

| 영역 | 구성 요소 | 상세 스펙 및 동작 인터랙션 |
| :--- | :--- | :--- |
| **1. 상단 네비게이션** | 핸들명(`@handle`), QR 버튼, 공유 버튼 | • `@handle`: 클릭 시 부드럽게 최상단으로 스크롤 (`smooth`)<br>• `[📷 QR]`: 클릭 시 전체화면 스크림(Scrim)과 함께 QR 모달 노출 (`SC-V02`)<br>• `[🔗 공유]`: Web Share API 실행 (미지원 브라우저 환경에서는 URL 클립보드 복사 토스트 팝업 노출, `SC-V03`) |
| **2. 프로필 히어로** | 아바타, 닉네임, 뱃지, 소개글, 소셜 링크 바 | • 아바타: `88px × 88px` 정원형 (TDS Subtle 테두리 + 섬세한 그림자)<br>• 뱃지: 블루 톤 라벨 (`bg-blue-50`, `text-blue-500`, `rounded-full`)<br>• 소개글: 최대 2~3줄 가독성 최적화 줄바꿈<br>• 소셜 링크 바: GitHub, Mail, Instagram 등 아이콘 버튼 탭 시 즉시 외부 채널 새 창 이동 |
| **3. 링크 목록 (Cards)** | 활성화된 링크 카드 (`F-04`, `F-07`) | • 카드 스타일: `bg-white` + `border border-grey-200` + `rounded-2xl`<br>• 상태 필터: 활성화된 링크만 표시 (`is_active = true`)<br>• 프레스 효과: 터치/클릭 시 `active:scale-[0.98]` 및 transition 애니메이션<br>• 비동기 로깅: 링크 클릭 시 목적지 새 탭(`target="_blank"`) 이동과 동시에 백그라운드로 클릭 이벤트 로그 전송 (`F-09`) |
| **4. 인터랙티브 섹션** | 응원 남기기 위젯 | • 방문자가 가볍게 인터랙션할 수 있는 하트 응원 버튼<br>• 클릭 시 하트 카운트 +1 애니메이션과 함께 최신 응원 한마디 실시간 노출 |
| **5. 바이럴 푸터** | 신규 생성 CTA 배너 | • 화면 하단 고정이 아닌 콘텐츠 최하단 플로우에 배치하여 프로필 열람 방해 방지<br>• 클릭 시 메인 랜딩 페이지(`/`)로 이동하여 30초 내 신규 링크 생성 유도 |

## 5. 디자인 토큰 & 스타일 규칙 (TDS 기준)

### 1) 레이아웃 & 컨테이너
- **너비**: 모바일 기본 `375px ~ 430px` (데스크톱 접속 시 가로 중앙 정렬 및 좌우 여백 `bg-[#F9FAFB]`)
- **패딩**: 좌우 기본 `px-5 (20px)`, 상하 섹션 간격 `py-6`

### 2) 타이포그래피 (Typography)
- **닉네임**: `text-xl font-bold text-grey-900`
- **소개글**: `text-sm text-grey-700 leading-relaxed`
- **링크 카드 제목**: `text-base font-semibold text-grey-900`
- **링크 설명**: `text-xs text-grey-600`
- **푸터 & 캡션**: `text-xs text-grey-400`

### 3) 색상 & 카드 스타일 (Colors & Cards)
- **배경색 (Background)**:
  - 뷰포트 배경: `bg-[#F9FAFB]` (`colors.grey-50`)
  - 카드 배경: `bg-white`
- **테두리 (Border)**: `border border-grey-200` (`#E5E8EB`)
- **라운드 (Border Radius)**:
  - 링크 카드: `rounded-2xl` (16px)
  - 소셜 버튼 / 뱃지: `rounded-xl` / `rounded-full`
- **포인트 & 뱃지**: `bg-blue-50 text-blue-500` (`#3182F6`)
- **터치 효과**: `active:scale-[0.98] transition-transform duration-100 ease-out`

### 4) 웹 접근성 & 성능 (Accessibility)
- 모든 링크 카드는 시맨틱 `<a>` 태그 적용 및 키보드 Tab 키 포커스 링 지원
- 아바타 이미지에 대체 텍스트(`alt`) 제공
- 링크 클릭 시 UI 블로킹 없이 새 탭 오픈 (`rel="noopener noreferrer"`)
